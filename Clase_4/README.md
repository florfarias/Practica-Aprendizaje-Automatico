# Regresión lineal con datos de libros

En este trabajo se aplicó un modelo de regresión lineal para predecir la
calificación de los libros utilizando como variables predictoras el número
de páginas, el género principal y el idioma.

## Archivos

- `regresion_lineal.ipynb`: notebook con la preparación, exploración
  y modelado de los datos.

## Dataset

El archivo CSV original no se encuentra incluido en el repositorio porque
supera el límite de tamaño permitido por GitHub.
